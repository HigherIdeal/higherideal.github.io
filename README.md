# 뱅! 온라인 살롱

[https://higherideal.github.io](https://higherideal.github.io) 에서 열리는 뱅! 베이스 게임입니다.
예전 포트폴리오 사이트는 `v1-backup` 브랜치에 그대로 있습니다.

친구에게 이 주소만 보내면 됩니다. 닉네임과 **오늘의 암호**를 입력하면 같은 테이블에 앉습니다. 최대 7명이고, 4명부터 시작할 수 있습니다.

## 입장 암호 바꾸기

암호는 `js/config.js`의 이 값 하나입니다.

```js
export const ENTRY_CODE = "3913";
```

숫자를 바꾼 뒤 `main`에 푸시하면 GitHub Pages에 반영됩니다. 암호 확인은 브라우저 안에서만 합니다. 서버 계정이나 결제되는 호스트는 필요 없습니다.

## 어떻게 연결되나

먼저 암호를 통과한 사람이 방장이 됩니다. 방장 브라우저가 [PeerJS](https://peerjs.com) 공개 중계로 방을 열고, 나머지 사람은 그 브라우저에 직접 붙습니다. 같은 컴퓨터의 여러 탭은 중계가 늦어도 서로 보입니다.

- 방장 탭은 판이 끝날 때까지 닫지 마세요. 방장이 새로고침하면 저장해 둔 판으로 다시 방을 엽니다.
- 다른 사람은 새로고침한 뒤 같은 닉네임 칸에 암호를 다시 넣으면 앉았던 자리로 돌아옵니다.
- 연결이 끊긴 사람은 잠시 후 자동으로 맞거나 턴을 넘깁니다. 방이 비면 입장 화면의 **내가 방장 되기**로 새 판을 열 수 있습니다.

## 규칙

베이스 게임만 있습니다. 보안관은 공개되고, 4인 보안관·배신자·무법자 2, 5인에 부관, 6인에 무법자, 7인에 부관이 추가됩니다. 인물은 두 장 중 하나를 고르고, 보안관은 생명력이 1 높으며 보안관부터 시작합니다.

거리, 무기, 야생마, 조준경, 감옥, 다이너마이트, 술통, 빗나감, 맥주(둘이 남으면 무효), 결투, 인디언, 기관총, 주점, 잡화점, 강탈, 캣 벌로우, 역마차, 웰스 파고, 탈락 보상과 벌칙, 16명 인물 능력을 처리합니다. 내 손패와 내 역할만 나에게 보이고, 보안관 역할은 모두에게 보입니다. 카드를 길게 누르면 커지고, 손을 떼면 제자리로 돌아갑니다.
